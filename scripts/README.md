# Scripts y comandos de apoyo

- `web-server-https-setup.sh`: instalación y habilitación de Apache HTTPS con certificado autofirmado.
- `test-vpn-connectivity.sh`: prueba ICMP + HTTPS desde la red de usuarios al servidor.
- `switch-setup.txt`: comandos usados para VLAN 10, trunk y puerto de acceso.

Los scripts están orientados a laboratorio y no deben copiarse sin adaptación a producción.
